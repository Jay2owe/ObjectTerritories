# Fiji smoke test

Checks that the built plugin jar loads in a real Fiji and that both commands
run end to end from a headless macro. Everything it needs is generated by
`make-fixtures.ijm`; no image data is stored in the repository.

## Run

Use a throwaway copy of Fiji: the script replaces any
`Object_Territories-*.jar` in its `plugins/` folder with the one just built.

```bash
./mvnw clean verify
cp -r /path/to/Fiji.app /tmp/fiji-smoke
bash scripts/fiji-smoke/run-smoke.sh /tmp/fiji-smoke /tmp/ot-smoke-work
```

The optional third argument sets the log folder (default `<work>/logs`).
Each macro writes `<prefix>-<name>.log` (standard output) and
`<prefix>-<name>.err.log` (standard error); the prefix is `ot-05-smoke`
unless `SMOKE_LOG_PREFIX` is set.

It prints one line per check and exits non-zero if any fails:

| Check | What it proves |
|---|---|
| `fixtures` | the synthetic 2D images, `.roi` region, 3D stacks and batch folders were written |
| `commands` | `Object Territories` and `Object Territories Batch...` are registered to the right classes |
| `2d` | a recorded-style 2D run writes the objects, interactions, regularity, map and 4 density files |
| `3d` | a 3D run with a region-mask stack writes a 6-slice territory stack and 4 density stacks |
| `batch2d` | the default (case-insensitive) filename pattern groups `.tif` and `.TIF` samples; both are processed and listed in `Batch_Manifest.csv` |
| `batch3d` | a 3D batch with `dimensions=3D region_mask_type=mask` processes both samples |
| `errors` | a bad option and a missing image each log one `[Object Territories] ERROR:` line, stop the macro, and print no stack trace |

The Windows launcher (`fiji-windows-x64.exe`) writes its console output only
when standard output is redirected to a file, which the script does. It
ignores `--console`. Each launch takes about 30 seconds.

## Manual checks (need a screen)

These cannot run headless. Tick them in a GUI Fiji with the same jar before a
release:

- [ ] `Plugins > Object Territories` opens its dialog listing the open images;
      with no images open it says to open a label image (2D or 3D stack).
- [ ] With `Plugins > Macros > Record...` open, a dialog run records one
      `run("Object Territories", "...")` line that replays identically.
- [ ] A run with density maps shows progress in the status bar, and pressing
      Escape stops it with the status `Object Territories cancelled`, no error
      dialog and no result windows.
- [ ] `Plugins > Object Territories Batch...` shows the preview; `Back` returns
      to the settings with the values just entered; `Run batch` runs and shows
      the manifest.
- [ ] Result windows open with the viridis (density) and glasbey (3D
      territories) lookup tables.
